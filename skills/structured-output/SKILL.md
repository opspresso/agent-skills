# 구조화 출력 스킬

비정형 텍스트(대화, 문서, 도구 결과)를 JSON, 표, CSV 같은 구조화된 형식으로
추출·변환할 때 따르는 지침이에요.

## 공통 규칙

- **스키마가 주어지면 그대로 따라요.** 필드를 추가하거나 이름을 바꾸지 않아요.
- **원문에 없는 값을 만들지 않아요.** 찾을 수 없는 필드는 `null`(JSON) 또는
  빈 칸으로 두고, 추론한 값이면 사용자에게 추론임을 밝혀요.
- **출력은 형식 그대로만.** 구조화 출력을 요청받으면 앞뒤 설명 문장 없이
  결과만 반환해요. 설명이 필요하면 결과 뒤에 짧게 분리해서 붙여요.
- 날짜는 `YYYY-MM-DD`, 숫자는 천 단위 구분 없이, 통화·단위는 별도 필드로
  분리하는 것을 기본으로 해요 (스키마가 다르게 정하면 스키마 우선).

## JSON

- 유효한 JSON만 출력해요 — 주석, trailing comma, 작은따옴표 금지.
- 코드 블록(```json)으로 감싸요.
- 스키마가 없으면 먼저 간단한 스키마를 제안하고 확인을 받은 뒤 추출해요.
  단, 요청이 명확하면 (예: "이름과 이메일만 뽑아줘") 바로 진행해요.
- 배열 항목의 키 순서를 모든 항목에서 동일하게 유지해요.

## 표 / CSV

- 표는 열 수를 5개 이하로 유지하고, 셀에는 값만 넣어요 (설명은 표 밖으로).
- CSV는 첫 줄에 헤더, 쉼표가 들어간 값은 큰따옴표로 감싸요.
- 정렬 기준이 있으면 명시하고 적용해요 (예: 날짜 내림차순).

## 검증

출력 전에 스스로 확인해요:

- 항목 수가 원문과 일치하는가 (빠뜨리거나 중복하지 않았는가)
- 모든 값이 원문에서 추적 가능한가
- JSON이라면 파싱 가능한 문법인가

원문이 모호해서 두 가지 이상으로 해석되는 값이 있으면, 임의로 고르지 말고
결과와 함께 해석 선택지를 알려요.
