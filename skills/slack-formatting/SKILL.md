# Slack 포맷팅 스킬

Slack으로 전송되는 답변을 작성할 때 따르는 지침이에요. Slack은 일반 마크다운이
아닌 자체 mrkdwn 문법을 쓰기 때문에, 익숙한 마크다운 습관을 그대로 쓰면
서식이 깨진 채 노출돼요.

## mrkdwn 문법

| 의도 | 일반 마크다운 (금지) | Slack mrkdwn (사용) |
|------|---------------------|---------------------|
| 굵게 | `**텍스트**` | `*텍스트*` |
| 기울임 | `*텍스트*` | `_텍스트_` |
| 취소선 | `~~텍스트~~` | `~텍스트~` |
| 인라인 코드 | `` `코드` `` | `` `코드` `` (동일) |
| 코드 블록 | ```` ``` ```` | ```` ``` ```` (동일, 언어 태그는 무시됨) |
| 인용 | `> 텍스트` | `> 텍스트` (동일) |
| 링크 | `[텍스트](url)` | `<url\|텍스트>` |

## 지원되지 않는 요소

- **헤더(`#`, `##`)** — 대신 `*굵은 한 줄*`로 섹션을 구분해요.
- **표** — 위 표 같은 마크다운 표는 렌더링되지 않아요. 짧으면 `항목: 값` 줄로,
  길면 코드 블록 안에 고정폭으로 정렬해요.
- **중첩 목록** — 한 단계 목록만 안정적이에요. `-` 또는 `•`를 쓰고 중첩이
  필요하면 문장으로 풀어요.
- **이미지 문법(`![]()`)** — 동작하지 않아요. URL만 남겨요.

## 메시지 관례

- 첫 한두 문장에 결론을 담아요. 채널에서는 긴 글보다 짧은 메시지가 읽혀요.
- 3,000자를 넘길 것 같으면 핵심만 남기고 상세는 스레드로 나누는 것을 제안해요.
- 스레드 안의 질문에는 스레드 맥락을 전제로 답하고, 앞서 나온 내용을 다시
  요약하지 않아요.
- 이모지는 의미를 보태는 곳에만 한두 개 사용해요. 모든 문단에 붙이지 않아요.
- 멘션(`@이름`)은 사용자가 요청했을 때만 포함해요.
