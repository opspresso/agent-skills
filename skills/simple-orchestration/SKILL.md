# 단순 오케스트레이션

복잡한 요청의 의존성과 완료 조건을 끝까지 추적하고, 서브에이전트 결과를 검증해
하나의 일관된 답변으로 통합해요. 단순히 적임자를 고르는 일은 Agent Studio의 기본
위임 지침에 맡기고, 이 스킬은 다단계 조정이 필요할 때만 사용해요.

## 판단

다음 중 하나에 해당하면 오케스트레이션해요.

- 서로 다른 전문 영역이 둘 이상 필요해요.
- 한 결과가 다음 단계의 입력이 되는 다단계 작업이에요.
- 여러 서브에이전트 결과 사이의 의존성이나 충돌을 관리해야 해요.

한 에이전트가 짧게 해결할 수 있는 요청은 나누지 말고 직접 처리해요.

## 절차

1. 사용자의 최종 목표와 완료 조건을 한 문장으로 정리해요.
2. 작업을 결과물 기준으로 나누고 선행 결과가 필요한 순서를 표시해요.
3. 각 단위에 필요한 전문성, 입력, 기대 출력과 검증 기준을 정해요.
4. 연결된 서브에이전트의 description을 비교해 현재 agent보다 적합할 때만
   `transfer_to_agent`를 호출해요.
5. 서브에이전트 결과를 원래 목표와 대조하고, 충돌·누락·근거 부족을 확인해요.
6. 사용자가 바로 쓸 수 있는 하나의 답변으로 통합해요.

## 위임 규칙

- 위임 메시지만 읽어도 작업할 수 있도록 목표, 관련 맥락, 제약, 기대 출력을 포함해요.
- 서브에이전트는 parent 대화 전체를 받지 않으므로 필요한 사실을 빠뜨리지 않아요.
- 사용자의 전체 대화를 그대로 전달하지 말고 필요한 정보만 전달해요.
- 같은 일을 여러 에이전트에게 중복 요청하지 않아요.
- 적합한 서브에이전트가 없으면 억지로 위임하지 않고 직접 처리해요.
- 서브에이전트 결과를 검토 없이 그대로 전달하지 않아요.
- 실패한 위임을 같은 입력으로 반복하지 않아요. 직접 처리하거나 부족한 입력을 확인해요.
- transfer 뒤 parent가 결과를 통합할 turn이 필요하므로 위임 횟수를 최소화해요.

## 통합

- 서로 다른 결과가 충돌하면 각 근거를 비교하고 확정할 수 없는 부분을 밝혀요.
- 중간 위임 과정이나 에이전트별 답변을 장황하게 나열하지 않아요.
- 최종 답변은 결론부터 제시하고, 필요한 근거와 남은 제한만 덧붙여요.
- 일부 작업만 완료됐다면 완료된 범위와 남은 작업을 구분해요.
